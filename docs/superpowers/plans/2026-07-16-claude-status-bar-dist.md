# claude-status-bar — Plan 3: Distribution + self-update (+ deferred UX polish)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.
> **DO NOT START until the Plan-2 live OAuth/endpoint verification (`docs/VERIFICATION-TODO.md`) has passed** — don't build a release/self-update pipeline on an app whose runtime core is unconfirmed.
> **When executing, re-check Sparkle specifics against current docs via the context7 MCP** (Sparkle version, `generate_appcast` flags, SwiftUI updater API can drift). This plan is grounded on Sparkle 2.x as of writing.

**Goal:** Ship claude-status-bar as an installable, self-updating macOS app WITHOUT an Apple Developer account: a "Check for Updates" flow via Sparkle (free EdDSA signatures), a GitHub Actions release pipeline that builds the unsigned `.app`, zips it, EdDSA-signs an `appcast.xml`, publishes both to a GitHub Release + GitHub Pages, and an `INSTALL.md` for the unsigned first-run. Plus a first milestone clearing the highest-value UX debt deferred from Plan 2 (user-visible error surface).

**Architecture:** Sparkle 2.x added to the Xcode app target via SPM (`project.yml`). `SPUStandardUpdaterController` lives in `@main`; a "Check for Updates…" button appears in the MenuBarExtra popover + Settings. EdDSA key pair generated once at the Mac (private key in login Keychain + a CI secret; public key in `Info.plist` `SUPublicEDKey`). A tag-triggered GitHub Actions workflow produces the release + appcast. `SUFeedURL` points at the GitHub Pages appcast URL.

**Tech Stack:** Sparkle 2.6+ (SPM), XcodeGen, GitHub Actions, GitHub Pages, `generate_keys`/`generate_appcast` (Sparkle tools), `xcodebuild` (unsigned), `ditto`/`zip`.

## Global Constraints

- **Unsigned / no Apple Developer account.** Ad-hoc code sign only (`CODE_SIGN_IDENTITY "-"`), `CODE_SIGNING_ALLOWED NO` in CI builds. Sparkle update authentication is **EdDSA** (free, no Apple account) — NOT Apple code signing.
- Drive Xcode locally via `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` (system xcode-select is CLT; no sudo). CI (macos-15) uses its default Xcode.
- SPM unit tests still run via the swift.org toolchain: `export PATH="$HOME/.swiftly/bin:$PATH"; swift test`. Tests are swift-testing.
- Secrets: tokens only in Keychain; never logged/rendered. The EdDSA **private key** is a secret — store it only in the login Keychain + a GitHub Actions repo secret (`SPARKLE_ED_PRIVATE_KEY`); NEVER commit it or print it. The **public** key is fine to commit (Info.plist).
- Bundle id `cz.mihalic.claude-status-bar`; app is LSUIElement, macOS 14+.
- Distribution artifacts: a versioned `ClaudeStatusBar-<version>.zip` (the zipped `.app`) attached to a GitHub Release; `appcast.xml` published to GitHub Pages at a stable URL used as `SUFeedURL`.
- `App/Info.plist` is generated by XcodeGen from `project.yml` `info.properties` — add Sparkle keys THERE, not by hand-editing the plist.

## Milestone B — Release pipeline

### Task 4: Release packaging script

**Files:**
- Create: `scripts/package.sh`

- [ ] **Step 1: Write `scripts/package.sh`** (build unsigned → zip the `.app` into `dist/`)

```bash
#!/usr/bin/env bash
set -euo pipefail
export DEVELOPER_DIR="${DEVELOPER_DIR:-/Applications/Xcode.app/Contents/Developer}"
VERSION="${1:?usage: package.sh <version>}"
rm -rf build dist && mkdir -p dist
xcodegen generate
xcodebuild -project ClaudeStatusBar.xcodeproj -scheme ClaudeStatusBar \
  -configuration Release -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
APP="build/Build/Products/Release/ClaudeStatusBar.app"
# Ad-hoc sign — Sparkle's generate_appcast rejects fully-unsigned apps ("failed Apple
# Code Signing checks"). Updates are still authenticated by the EdDSA SUPublicEDKey.
codesign --force --deep --sign - "$APP"
codesign --verify --deep --strict "$APP"
# ditto preserves symlinks/permissions Sparkle needs
ditto -c -k --sequesterRsrc --keepParent "$APP" "dist/ClaudeStatusBar-$VERSION.zip"
echo "dist/ClaudeStatusBar-$VERSION.zip"
```

### Task 5: GitHub Actions release workflow

**Files:**
- Create: `.github/workflows/release.yml`

**Interfaces:** on `push` of a `v*` tag → build + zip → generate/sign appcast (EdDSA key via stdin from `SPARKLE_ED_PRIVATE_KEY`, since the `-s` flag is deprecated) → create the GitHub Release with the zip → publish `appcast.xml` to GitHub Pages.

- [ ] **Step 1: Write `.github/workflows/release.yml`**

```yaml
name: Release
on:
  push:
    tags: ["v*"]
permissions:
  contents: write
  pages: write
  id-token: write
jobs:
  release:
    runs-on: macos-15
    steps:
      - uses: actions/checkout@v4
      - name: Install XcodeGen
        run: brew install xcodegen
      - name: Package unsigned .app
        run: |
          VERSION="${GITHUB_REF_NAME#v}"
          ./scripts/package.sh "$VERSION"
      - name: Sign appcast (EdDSA via stdin)
        env:
          SPARKLE_ED_PRIVATE_KEY: ${{ secrets.SPARKLE_ED_PRIVATE_KEY }}
        run: |
          # Locate Sparkle's generate_appcast from the resolved SwiftPM artifacts.
          # `|| true`: find exits non-zero if a path arg (DerivedData) doesn't exist on a fresh
          # runner, which under `set -e` would abort before the guard below. The guard handles empty.
          GEN=$(find ~/Library/Developer/Xcode/DerivedData build -name generate_appcast -type f -print -quit 2>/dev/null || true)
          [ -n "$GEN" ] || { echo "generate_appcast not found — resolve Sparkle first"; exit 1; }
          mkdir -p public
          # Pass the private key on stdin (NOT the deprecated -s flag). Confirm the exact
          # stdin/keyfile invocation against current Sparkle docs at execution.
          printf '%s' "$SPARKLE_ED_PRIVATE_KEY" | "$GEN" --ed-key-file - --download-url-prefix \
            "https://github.com/ivan-mihalic/claude-status-bar/releases/download/${GITHUB_REF_NAME}/" dist/
          cp dist/appcast.xml public/appcast.xml
      - name: Create GitHub Release + upload zip
        env: { GH_TOKEN: ${{ github.token }} }
        run: gh release create "${GITHUB_REF_NAME}" dist/ClaudeStatusBar-*.zip --title "${GITHUB_REF_NAME}" --generate-notes
      - name: Upload Pages artifact
        uses: actions/upload-pages-artifact@v3
        with: { path: public }
  deploy-pages:
    needs: release
    runs-on: ubuntu-latest
    environment: { name: github-pages, url: "${{ steps.deploy.outputs.page_url }}" }
    steps:
      - id: deploy
        uses: actions/deploy-pages@v4
```

> Note: enable GitHub Pages (Settings → Pages → Source: GitHub Actions) once. The `SUFeedURL` in Info.plist must equal `https://ivan-mihalic.github.io/claude-status-bar/appcast.xml`. Verify `generate_appcast`'s stdin/`--ed-key-file` invocation against current Sparkle docs (context7) at execution — the exact flag matters and Sparkle deprecated `-s`.

```markdown
# Installing Claude Status Bar

Download the latest `ClaudeStatusBar-<version>.zip` from
[Releases](https://github.com/ivan-mihalic/claude-status-bar/releases), unzip, and move
`ClaudeStatusBar.app` to `/Applications`.

## First launch (unsigned app)
This app is not notarized by Apple, so Gatekeeper blocks the first open. Do ONE of:
- **Right-click** the app → **Open** → **Open** (only needed once), OR
- `xattr -dr com.apple.quarantine /Applications/ClaudeStatusBar.app`

It runs as a **menu-bar app** (no Dock icon) — look for the gauge icon in the top-right.

## Updates
The app self-updates via **Sparkle** ("Check for Updates…" in the menu-bar popover, plus
automatic checks). Updates are EdDSA-signed; Sparkle-delivered updates aren't re-quarantined,
so after the one-time first-launch step, updates install without the Gatekeeper prompt.

Note: unsigned builds may re-prompt for Keychain access after an update (the binary signature
changes) — click **Always Allow**.
```
